## Hub Features

- Illustrated cards introducing each tool.
- Direct application links that open in a new tab.
- Search by tool name, description, category, or feature.
- Links to source repositories and feedback channels.
- Responsive layout for desktop and mobile screens.
- Creator information and contact details.

## Use Locally

1. Select **Code → Download ZIP**.
2. Extract the downloaded archive.
3. Open **index.html** in a modern browser.
4. Browse or search the tools, then select **Open tool**.

The hub requires no installation, build process, API key, or application server. Internet access is required to open the linked hosted tools and GitHub repositories.

## Publish with GitHub Pages

1. Place the hub HTML file at the repository root, named **index.html**.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then select **Save**.
5. Check the deployment status in **Actions** and open the website once deployment succeeds.

The project website address is:

https://mohammedhosam5-tech.github.io/Tools-Hub/

## Data and Backups

The hub is a launch page. It does not store the records entered in the linked applications.

The trackers store their records in browser storage. They do not automatically synchronize data between users, browsers, or devices. Export backups regularly and before clearing browser data, moving the application, or changing devices.

GitHub Pages projects under the same account share a browser origin. Separate repository paths do not provide isolated browser-storage security boundaries. Keep sensitive information on devices and in environments you trust.

See each application's README for its dependencies, storage behavior, and limitations.
